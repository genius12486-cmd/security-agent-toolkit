# 실행과 변경 기록 

- 처음 적은 x의 값과 출력 : 3, 8
- 고친 x의 값과 출력 : 5, 10
- 저장, 커밋, 푸시의 차이 : \
**저장**은 코드편집상태를 컴퓨터의 디스크에 저장하는방법이다.
저장하면 기존 저장본에 덮어씌워진다.\
**커밋**은 주요 변경사항이 생길때마다 깃에 내 파일의 상태를 저장하는것으로 커밋할때마다 고유번호가 부여되기 때문에 덮어씌워지지않고 매번 새로 저장된다. 문제가 발생했을때 이전 커밋해놨던 상태로 돌아가는데 사용할 수 있다.\
**푸시**는 내가 만든 폴더를 깃허브로 올리는것이다.
- 막혔던 곳과 확인한 방법 : 딥시크에게 물어보면 알려준다.
